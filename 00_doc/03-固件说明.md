# 固件说明

车机固件跑在 **SiFli SF32LB52** 上，内核是 **openvela / NuttX**。
代码在 `02_sw/vendor/vela_sifli/`（git submodule），本文件只讲结构，不讲怎么编
（那是 [06-构建与烧录.md](06-构建与烧录.md)）。

## 启动链

上电后要经过三级才到应用：

```
Mask ROM
   │  从 SD/eMMC 的 boot 分区读二级 bootloader 到 SRAM
   ▼
二级 bootloader（2SFBL）        boot_loader/
   │  · 自带一个小 msh 和 KV LittleFS
   │  · 读分区表（ftab.bin）决定从哪个存储介质启动
   │  · 用 OVNX 头把 NuttX 镜像拷进 PSRAM 再跳过去
   ▼
NuttX（openvela）               boards/sf32lb52/my_vendor/
   │  · 挂文件系统、起服务与 UI
   ▼
应用（bicycle 码表）
```

几个概念：

- **2SFBL** 是这套东西里最"自己攒"的部分：它有自己的 msh 命令（比如 `factory` 跳到工厂镜像），
  也挂着 KV LittleFS 存配置。开发约定和烧录踩过的坑在固件仓库的
  `docs/boot_2sfbl.md`。
- **ftab.bin + bootloader.bin** 由 `02_sw/vendor/vela_sifli/boot_loader/build.sh` 产出，
  一起装进 SD 镜像。
- **NuttX 启动顺序**里有不少"隐性登记"的资源（不会在业务代码里 `register()`，却在 CMake/Kconfig/ROMFS
  里登记），弄不清会出"改了 rcS 不生效""命令找不到"这类问题。固件仓库的
  `docs/nuttx_boot_flow.md` 专门讲这个。

## 存储布局

SD/eMMC 上是**两卷 LittleFS + 一卷 FAT**：

| 卷 | 用途 |
|---|---|
| `kv` | 配置、配对信息、按版本存放的固件镜像（`/mnt/kv/fw/<版本>.bin`） |
| `main` | 主文件系统 |
| FAT | 余量卷，也是 PC 能直接读的那卷 |

**分区表的唯一源**是 `boot_loader/config/nsh/ptab.sdmmc.json` —— 改布局要先改这份 JSON，
再同步头文件并重新生成 `ptab_table.{c,h}`，不要手改生成物。
细节见固件仓库 `docs/sd_partition.md`。

产品固件**优先从 KV 里的版本化镜像加载**，SD 的 `main` 分区只作回退；
工厂模式是一套**独立的 NuttX 镜像**，由 2SFBL 的 msh 命令 `factory` 跳进去，
不在 2SFBL 里做 MTP。见固件仓库 `docs/fs_firmware.md`、`docs/factory_firmware.md`。

## 界面

UI 是 LVGL，代码在 `boards/sf32lb52/my_vendor/ui/bicycle/`：

| 文件 / 目录 | 作用 |
|---|---|
| `src/lvgl_page/helm_shell.c` | 外壳：顶栏 24px 黑条 + 内容区 240×296。**界面尺寸常量以它为准** |
| `src/lvgl_page/helm_palette.h` | 调色板。颜色是 `helm_color()` 的整数变换结果，不是直接写 RGB |
| `src/lvgl_page/helm_font.c` | 字体与**回退链**（`mism4_12 → ui_12` 等） |
| `src/lvgl_page/helm_icon.c` | 顶栏 16×16 图标 |
| `src/lvgl_page/helm_menu.c` | 菜单 |
| `src/lvgl_page/helm_toolbox.c` | 工具箱 |
| `src/lvgl_page/live_map/` | 五个页面里用到地图的那两页 |
| `src/vmap/` | 矢量地图渲染（详见下节） |

两个**板级硬约束**，改界面之前先知道：

1. **12px / 15px 点阵字库的有效覆盖只有 546 字**。实测缺「黄、预、台、部、学」等，
   所以文案要避开（"全部数据"改成了"骑行数据"、"预计到达"改成了"剩余时间"）。
2. **半透半反屏上彩色小字一律不达标**——橙色只有 2.66:1 对比度。所以文字用黑，
   颜色只用来做形状（色条 / 量条 / 环）和状态（越区才变色）。

改界面有个**不用烧录的预览器**，几秒出图且像素级可信，见 [05-地图工具链.md](05-地图工具链.md) 末节。

## 矢量地图

车机跑的是**自研的离线矢量地图**，不是瓦片图片：

- 设备包按 **3 km 网格**切成一格一个 `.vpk`，目录是 `lon*/lat*/x*_y*.vpk`。
- 地图是**常驻画布**：显示/隐藏不新建实例、不多占内存；渲染泵是 kick 驱动、干完自停，
  所以**静止的地图不花资源**。
- 真正的开销在"持续动地图"：8 fps 平移约吃 8% PSRAM 带宽，30 fps 约 31%。
- 离线算路用随地图包一起下发的路网（VGRF）。

地图包怎么做出来，见 [05-地图工具链.md](05-地图工具链.md)。

## 蓝牙

车机同时是两种角色：

- **Central**：连心率带（`0x180D`）、踏频计（`0x1816`）、功率计（`0x1818`）。
  台架上用 `02_sw/esp32/` 的三个模拟器代替真传感器。
- **Peripheral**：被手机 App 连，接收配置、上报实时数据与记录、接收固件升级。

配对信息落在 KV 里。**注意**：如果手机换过系统或清过蓝牙，可能需要在设备侧重开配对窗口
（`ctl pair open`），否则会出现"连不上但要等冷却"的现象。

## GNSS

内置 GNSS 模组，走 UART2 与控制台共用 DMA RX。定位数据经 NMEA 解析后进骑行状态；
星历可以离线注入，避免冷启动慢。相关文档在固件仓库的 `docs/gnss_*.md`。
