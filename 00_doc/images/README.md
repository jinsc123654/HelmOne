## 规格建议

- **格式**：照片用 JPG，界面用 PNG。
- **尺寸**：长边 1600~2000px 足够（文档里不会更大显示）；别直接塞手机原图。
- **体积**：单张尽量 < 500 KB。图多了仓库会变重。
- **隐私**：实拍前留意屏幕上有没有不该公开的信息（位置、配对设备名等）。
